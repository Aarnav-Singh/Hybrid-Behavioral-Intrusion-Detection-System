# Contributing to HB-IDS

We welcome contributions to the Hybrid Behavioral Intrusion Detection System!

## Getting Started

1. Set up the development environment using `./scripts/dev_setup.sh`.
2. Ensure you branch off `dev` for all feature work.
3. Write PyTest instances inside `backend/tests/` for any new backend features.
4. Run `make lint` and `make test` prior to opening a PR.

## Security

If you discover a security vulnerability or bypass technique in the adversarial robustness metrics, please open a standard issue; this project's purpose is to publicly track evasion capabilities and defenses.
